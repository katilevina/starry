# External References Library

Внешние материалы, которые усиливают наши скиллы: гайды, статьи, скриншоты, конспекты курсов, PDF, видео-транскрипты и т.д.

## Структура

Папки названы по именам скиллов из `.claude/skills/`. Каждая папка содержит:
- `sources.md` — таблица-индекс источников
- Сами материалы (любого формата: `.md`, `.png`, `.jpg`, `.pdf`, ...)

Также есть папка `general/` — для материалов, не привязанных к одному скиллу (общие гайды по job hunt, переговорам, networking и т.д.).

## Как добавить материал

1. Положи файл в нужную папку (`references/cover-letters/`, `references/job-analysis/` и т.д.)
2. Добавь строку в `sources.md` этой папки: файл, источник, автор, тип, язык, дата, доступ
3. Если в `SKILL.md` соответствующего скилла нет ссылки на эту папку — добавь секцию "External References"

## ⚠️ При создании нового скилла

Когда добавляешь новый скилл в `.claude/skills/`, обязательно:
1. Создай папку `references/[skill-name]/`
2. Создай в ней `sources.md` (скопируй из любого существующего и почисти таблицу)
3. Добавь секцию "External References" в `SKILL.md` нового скилла

Это правило также продублировано в `CLAUDE.md`.

## Что в git, что не в git

| Коммитим | Игнорируем |
|----------|------------|
| `references/README.md` | Сам контент материалов (`.md`, `.png`, `.pdf`, ...) |
| `references/[skill]/sources.md` | Всё остальное в подпапках |
| Структуру папок (через sources.md как маркер) | |

Логика: шаблон проекта остаётся публичным, контент материалов — локально на твоей машине. Это важно для лицензий: ты можешь хранить конспекты платных курсов локально, но не публиковать их в открытом репо.

См. `.gitignore` — раздел `External references library`.

## Типы источников

| Тип | Пример |
|-----|--------|
| `course_notes` | Конспект урока курса |
| `article` | Статья в блоге/медиа |
| `book_excerpt` | Выдержка из книги |
| `video_transcript` | Транскрипт видео/подкаста |
| `blog_post` | Пост из личного блога эксперта |
| `screenshot` | Скриншот примера (LinkedIn, переписка, JD, объявление) |
| `pdf` | PDF-документ |
| `other` | Всё остальное |

## Уровни доступа

| Доступ | Что значит |
|--------|------------|
| `open` | Свободный источник, можно шарить и при желании коммитить публично |
| `closed` | Платный курс/материал под копирайтом — **НЕ** коммитить публично |
| `personal` | Твои личные конспекты/заметки |

## Связь со скиллами

В `.claude/skills/[name]/references/` лежат **наши** шаблоны и примеры (source of truth для скилла). А здесь, в `/references/[name]/`, — **внешка**, которая может подсказать новые приёмы, дать примеры или просто напомнить о чём-то. Если что-то из внешки оказалось особо ценным — можно вытащить идею и инкорпорировать в наш собственный шаблон/гайд в `.claude/skills/`.
